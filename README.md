**UNVAL APP** o **UNI-VERSE-ALL** es una plataforma móvil moderna diseñada para la comunidad universitaria y estudiantil. Facilita la conexión entre estudiantes, el intercambio de recursos a través de un marketplace, la búsqueda de tutorías y la gestión de comunidades académicas.

Este proyecto está construido con **React Native** utilizando el ecosistema de **Expo** y **TypeScript**.

## ✨ Características Principales

- 🛒 **Marketplace Estudiantil:** Vende o compra libros, materiales y otros artículos de interés académico.
- 🎓 **Tutorías y Clases:** Encuentra o ofrece ayuda en diversas materias (Cálculo, Programación, etc.).
- 👥 **Comunidades:** Espacios para interactuar con estudiantes de diferentes carreras.
- 🌓 **Modo Oscuro/Claro:** Interfaz adaptativa según las preferencias del sistema o del usuario.
- 🌐 **Multi-idioma:** Soporte completo para Español e Inglés.
- 📱 **Navegación Fluida:** Implementada con Expo Router para una experiencia de usuario nativa.

## 🛠️ Requisitos Previos

Antes de comenzar, asegúrate de tener instalado lo siguiente:

- **Node.js** (Versión LTS recomendada)
- **npm** o **yarn**
- **Git** (para control de versiones)

### Extensiones Recomendadas (VS Code)
Para una mejor experiencia de desarrollo, te sugerimos instalar estas extensiones:
- **ES7+ React/Redux/React-Native snippets**: Atajos de teclado para componentes.
- **Prettier - Code formatter**: Para mantener un estilo de código consistente.
- **ESLint**: Para detectar errores de sintaxis y código.
- **Expo Tools**: Integración directa con las herramientas de Expo.

## 🚀 Instalación y Uso

Sigue estos pasos para correr el proyecto localmente:

1. **Clonar el repositorio:**
   ```bash
   git clone <url-del-repo>
   cd UNVAL_APP
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npx expo start
   ```

4. **Visualizar la App:**
   - **Dispositivo Físico:** Descarga la app **Expo Go** (disponible en Play Store y App Store), abre la cámara y escanea el código QR que aparece en tu terminal.
   - **Emulador Android/iOS:** Presiona `a` para Android o `i` para iOS en la terminal si tienes los emuladores configurados.
   - **Web:** Presiona `w` para abrir la versión web en tu navegador.

## 📂 Estructura del Proyecto

El proyecto está organizado de la siguiente manera:

- `app/`: Contiene las rutas y pantallas principales (Expo Router).
- `components/`: Componentes reutilizables de la interfaz de usuario.
- `assets/`: Imágenes, fuentes y otros archivos estáticos.
- `constants/`: Temas, colores, contextos de traducción y configuración global.
- `node_modules/`: Dependencias del proyecto.

## 💻 Desarrollo

- **Lenguaje:** TypeScript
- **Framework:** React Native + Expo
- **Estilos:** StyleSheet (Vanilla CSS-in-JS)
- **Navegación:** Expo Router (basado en archivos)
